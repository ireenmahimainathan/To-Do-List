# To-Do-List

To-Do List CLI Application

📝 Description

A command-line to-do list application developed using Python. It allows users to add, view, and remove tasks through a simple menu-based interface.

🛠️ Technologies Used

- Python 3
- Lists
- Functions
- Loops
- Conditional Statements
- User Input
- Exception Handling

▶️ Instructions

1. Open the project in VS Code or any Python IDE.
2. Run the program using:

python todo_list.py

3. Choose an option from the menu:
   - Add Task
   - View Tasks
   - Remove Task
   - Exit
4. Follow the instructions displayed in the terminal.
